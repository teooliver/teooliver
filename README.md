### Hi there, I'm Teo 👋

> Engineering Manager who still writes code. I've spent my career building software, and now I lead teams and build an environment where engineers do their best work.

I started as a game and web developer and over time grew into leading teams. Today I focus on growing engineers, building healthy team practices, and connecting technical decisions to product and business goals.

Moving into management didn't mean leaving the code behind. I still program regularly, and I use side projects to keep learning and try out languages, tools, or techniques I don't get to use day to day.

### 🚀 Side projects:

- 🦀 [Time Tracker Base (Server)](https://github.com/teooliver/ttb-server) - Rest API example built with Rust, Warp and MongoDB.

- 🦀 [rust-identicon](https://github.com/teooliver/rust-identicon) - Generate Identicon images based on a given string.
- 🟣 [HabitGrid](https://habitgrid.xyz) - A Habit Tracker PWA built with React, Redux, Dexie.js and Sass.
